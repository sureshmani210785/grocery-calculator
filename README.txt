GROCERY RATE & TOTAL CALCULATOR

Included:
- Add/remove grocery items
- Quantity x rate automatic item totals
- Subtotal, discount, grand total, amount paid and balance/change
- Save and reload bills on the same device/browser
- Copy bill details
- Mobile-friendly installable web app (PWA)

HOW TO USE
1. Open index.html to test the calculator on a computer.
2. To install it like an app on a phone, the files need to be hosted on an HTTPS website.
   You can use a static hosting service such as GitHub Pages or Netlify.
3. Open the hosted HTTPS address in your phone browser.
   Android/Chrome: menu (three dots) > Install app or Add to Home screen.
   iPhone/Safari: Share > Add to Home Screen.

IMPORTANT
- This is a starter web app, not an app-store-published Android APK or iPhone app.
- Saved bills stay in the browser storage on that device. They do not sync between devices.
- Export or back up important bills separately; clearing browser data may remove saved bills.
